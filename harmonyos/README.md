# Showly HarmonyOS Preview

Unofficial independent ArkTS Stage-model prototype, not a full port of upstream Showly. The preview offers only a temporary in-memory watch queue; no network, accounts, persistence, synchronization or real-device testing yet. No credentials or signing material included. The existing Android project remains unchanged. Target API 24, minimum API 12 (device compatibility not verified).

CI: see `.github/workflows/harmonyos-bootstrap.yml`. Unsigned HAP artifacts are for experimental build validation, not production distribution. Do not use them as a replacement for existing user data.
