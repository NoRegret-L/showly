# v0.9.2a 迁移与只读预览

## 不变量
- 旧收藏每条记录及顺序保留；旧 Preferences 永远不写、不删。
- 新库快照单行 INSERT/UPDATE 原子提交；首次备份和迁移快照同一次 INSERT；已有快照不覆盖。
- 旧 watched 不代表明确云端意图，两个新字段均为 unknown。
- 电影观看状态与待看状态独立；剧集不得生成电影观看意图。
- 云端导入、未知状态、仅云端存在均不产生新增/删除意图。
- 使用当前已绑定 UUID、完整分页和活动快照验证；只读预览，禁止标题级远端写入。
- 不提供降级同步或恢复旧数据操作。旧快照保留不等于可以安全卸载或回退。新库读取失败时关闭收藏写入，旧快照只用于临时查看。

## 预期测试矩阵（尚未真机执行）
| 输入 | 预期 |
|---|---|
| 旧电影 watched=true，旧电影 watched=false，旧剧集，手动条目 | 全部原样保留，两状态 unknown |
| 重启已有 v2 库 | 不重新覆盖，不重复导入 |
| 电影 watched=yes + watchlist=yes | 同时存在已看及待看 |
| 电影 watchlist=no | watched 不变，全部分类仍存在 |
| 本机 unknown + 云端存在/不存在 | 未知，无写入 |
| 本机 yes + 云端不存在 | 新增候选，无写入 |
| 本机 no + 云端存在 | 冲突，无删除 |
| 本机 yes + 云端存在 / no + 云端不存在 | 一致 |
| 仅云端存在 | 保留，无写入 |
| 分页不完整、活动变化、UUID 不匹配 | 不生成可用预览 |
| 数据库异常 | 禁止写入，不删除旧数据 |

## 后续限制
快照不是完整归一化关系模型，规模增大时需测量并决定按行索引。没有记录电影实际播放时间或账户归属，不能直接自动上传；下一版本需为明确确认的账户和动作生成持久操作凭证。待看移除不得清除历史。没有云端删除或自动写入。
