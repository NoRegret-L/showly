# Build 58: commit fence and row-local publication

Baseline Android Room/EpisodesDao/ShowsDao/MoviesDao and RecyclerView adapter bindings (e08cb90b). No new dependencies or thresholds. Projection-affecting EpisodeStore writes own a single fail-closed fence; nested existing transactions use private bodies. Durable cache version changes on success; rollback invalidates in-flight readers but retains a prior committed cache key; potentially partial non-atomic failures invalidate conservatively. Current account scope, read evidence and sync guards are retained. A separate input version compares exact records once per publication, retaining order, not at each projection lookup. Existing per-show persistent cache and per-show evidence signatures remain authoritative for reuse. Changes include exact known IDs and conservative account-wide invalidation where source payload is account-scoped. Native row dependencies map media IDs to current row indices (including grid pairs and repeated calendar entries); one changed poster updates only affected row signatures. ArkUI content-key changes intentionally recreate changed native rows while logical identity/anchors and unaffected keys stay stable. Title tie-breaking in show progress and user-rating sorting is retained. Projection read fencing rejects overlap; it is not a database-wide transaction isolation mechanism for every sync table. No schema migration. Device frame, component and memory performance not measured.
